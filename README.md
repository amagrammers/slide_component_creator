# プレゼン資料 部品作成ツール

プレゼン資料で使う部品（図形・アイコンなど）を作成し、PNG画像として保存するデスクトップアプリケーションです。
部品を選んで設定を調整し、必要に応じて背景を透過して書き出せます。

## 技術スタック

- C# (.NET 10)
- WPF

## 画面構成

画面は大きく3つの領域で構成されます。

| 領域 | 内容 |
| -- | -- |
| 大分類選択 | 基本図形 / アイコン |
| 小分類選択 | 大分類に応じて切り替わる（例: 矢羽根、四角、矢印） |
| メイン画面 | 図形のプレビュー、設定フォーム、保存ボタン |

### 設定フォーム

- ベース色
- 高さ
- 幅
- その他（部品ごとの項目）

### 保存

保存ボタンで、プレビュー中の部品をPNG画像として書き出します。画像の透過にも対応します。

## ディレクトリ構成

| パス | 説明 |
| -- | -- |
| `src/` | プログラム本体 |

## 開発環境

- .NET 10 SDK
- Windows（WPF のため）

## ビルドと実行

```powershell
dotnet build src
dotnet run --project src
```

※ プロジェクトの配置に合わせて、パスは適宜読み替えてください。
